## 2023-10-25 - Consistent Keyboard Focus Indicators
**Learning:** Found multiple interactive elements across the application (custom CSS-styled ghost nav links/thumbnails/arrows, and Tailwind-styled submit button/footer links) lacking proper keyboard focus indicators, breaking keyboard accessibility (WCAG 2.1 SC 2.4.7 Focus Visible). Relying entirely on hover states is a common pitfall.
**Action:** Always verify keyboard accessibility (`Tab` key navigation) alongside mouse interactions. Standardize the focus indicator using the brand's primary accent color (gold ring: `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-gold` for Tailwind, or `outline: 2px solid var(--color-gold)` for custom CSS) and utilize `:focus-visible` over `:focus` to prevent triggering the outline on mouse clicks.
